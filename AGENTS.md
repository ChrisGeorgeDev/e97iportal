## Working with this repo

- Don't spend time verifying UI/route changes with `curl`, spinning up the dev server, or other manual runtime checks after implementing them — the user checks results themselves in the browser. `npm run build` (or type-check) is still worth running since it's cheap and catches real breakage. Skip further "does it look right" checks unless actively debugging a reported bug or explicitly asked to confirm something.
